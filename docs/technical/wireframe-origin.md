# Existing SmartMeal wireframe

The repository initially contained only README, AGENTS.md and prompt-log templates. The existing editable SmartMeal prototype from the current authorized workspace is imported under `app/wireframe/`; it is not a new implementation or a replacement design.

This baseline contains the previously delivered low-fidelity prototype and its source modules. All records are labeled demonstration data. Character and recipe artwork remains replaceable. Authentication, cloud synchronization, audio and AI generation are simulated; importing this prototype does not make them production services.

The baseline is kept separately in Git history so the subsequent requested fixes have an inspectable diff. No official PRD is imported or modified.
